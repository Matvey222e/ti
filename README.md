# Кликер

Простое Android-приложение-кликер: жми на кнопку, копи монеты, покупай улучшения
(+1 за клик и автокликер). Прогресс сохраняется.

## Как скачать APK

APK собирается автоматически на GitHub после каждого пуша:

1. Открой на телефоне вкладку **Releases** этого репозитория → релиз **latest**.
2. Скачай `clicker.apk` и открой его.
3. Если Android ругается — разреши установку из неизвестных источников для браузера.

Собрать самому: `./gradlew assembleDebug` (нужен Android SDK), APK будет в
`app/build/outputs/apk/debug/`.
